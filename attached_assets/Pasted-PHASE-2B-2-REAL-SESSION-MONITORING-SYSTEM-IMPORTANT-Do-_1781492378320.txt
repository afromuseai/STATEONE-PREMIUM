PHASE 2B.2 — REAL SESSION MONITORING SYSTEM

IMPORTANT:

Do NOT modify:

* authentication logic
* billing logic
* project architecture
* usage tracking
* notifications system
* plan enforcement
* admin role system

Build this as a new admin capability.

====================================
GOAL
====

Allow administrators to see:

* who is currently online
* active sessions
* session duration
* last activity
* current page
* user activity feed

The admin should understand platform usage in real time.

====================================

========

Indexes:

userId
sessionId

lastSeenAt

====================================
SESSION TRACKING
================

When user logs in:

Create session record.

Update:

startedAt
lastSeenAt
isActive=true

Every 30–60 seconds:

Heartbeat updates:

lastSeenAt
currentPage

When user logs out:

isActive=false
endedAt=timestamp

====================================
ONLINE STATUS
=============

User is ONLINE if:

lastSeenAt < 2 minutes

User is OFFLINE if:

lastSeenAt > 2 minutes

Do NOT rely on browser close events.

Heartbeat controls status.
