Phase 1 — Commit 4
Wire Marcus Conversation Engine into the Website Generation SSE Pipeline
Goal

The Marcus Conversation Engine already exists but is isolated.

This commit integrates it into the existing /api/generate/website-v2 pipeline so the frontend receives rich agent events instead of only raw generation progress.

The conversation layer must remain independent from the Architect and Code Generator models.

Marcus should narrate real work while the LLM performs the work.

Objectives

Integrate MarcusConversationEngine into:

artifacts/api-server/src/routes/generate-website-v2.ts

without changing the existing Architect or Code Generator prompts.

Do not remove any existing SSE events.

Instead, extend the stream.

New SSE Event

Extend the V2 SSE event union with:

{
    phase: "agent";
    event: AgentEvent;
}

Every AgentEvent generated by Marcus should be streamed through this event.

The frontend will later render these as chat messages.

File Operation Integration

Every real file operation should emit a FileActivityEvent.

Examples:

Creating app/layout.tsx

Creating app/page.tsx

Creating components/Navbar.tsx

Updating app/globals.css

Creating package.json

Creating tsconfig.json

Creating postcss.config.mjs

Saving project

Only emit events for real operations.

Do not fabricate files.

Infrastructure Injection

Replace silent behavior with conversation events.

Creating it automatically.

tsconfig.json
postcss.config.mjs

Error Integration

Replace generic failures like:

with structured conversation.

Example:

Then emit the existing error event.

Conversation should always precede errors.
