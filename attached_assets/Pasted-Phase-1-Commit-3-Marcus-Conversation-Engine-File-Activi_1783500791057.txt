This commit must NOT modify the website generation pipeline yet. The objective is to build the conversation/event layer that will later plug into SSE.

Objective

Implement a dedicated Marcus Conversation Engine that generates rich agent conversations independently from the LLM output.

The conversation engine must never stream raw model JSON or prompt text to the user.

Instead, it should translate controller lifecycle events into natural engineering progress updates similar to Replit Agent.

Create
artifacts/api-server/src/lib/agents/marcus-conversation.ts
Responsibilities

Create a conversation engine responsible for converting controller activity into user-facing events.

The conversation layer must not call any LLM.

It is purely deterministic.

Input:

Marcus phase changes
controller lifecycle
file operations
warnings
retries
validation
completion

Output:

AgentEvent objects.

Each event should include:

The event system should be extensible because future modules (Automation Studio, Chatbot Studio, Agent Builder) will reuse it.

The conversation engine must:

be deterministic
avoid direct dependency on Website Studio
remain reusable for future AI modules
