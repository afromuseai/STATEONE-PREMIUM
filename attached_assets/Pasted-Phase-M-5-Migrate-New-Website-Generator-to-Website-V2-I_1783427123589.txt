Phase M.5 — Migrate New Website Generator to Website V2 Infrastructure
Objective

Complete the transition from the current Website Generator architecture to the new Website V2 architecture.

The goal is that every new website generated by users becomes a real website_v2_project that can immediately open inside Website Studio.

Current state:

New Website Generator UI
        |
        |
        ?  (not connected)
        |

        |

    ↓

    |
    ↓
Blueprint Agent
    |
    ↓
Code Generation Agent
    |
    ↓

    |
    ↓

Step 1 — Map the New Website Generator Architecture

Before changing anything:

Find:

new Website Generator frontend page
generator hooks/state
API routes
orchestration logic
streaming handlers
current generation response handling

Do NOT modify the old generator.

Confirm which files belong to the new architecture.

Step 2 — Replace Generation Backend Connection

The new Website Generator should call the Website V2 generation pipeline.

Connect it to:

POST /api/generate/website-v2

(or the current V2 orchestrator route if renamed)

The generation lifecycle should be:

start
 |
 ↓
architect
 |
 ↓
blueprint
 |
 ↓
building
 |
 ↓
project-created
 |
 ↓
project-ready

 phase:"architect"
}

{

}

 }

Display:

✓ Preparing Website Studio
Step 4 — Return Project ID

The final generation response must expose:

{
 projectId:string,
 status:"ready"
}

The frontend should store this.

Step 5 — Automatic Studio Launch

After successful generation:

Current:

Generation completed
↓
Show preview

Change to:

Generation completed
↓
Open Website Studio
↓
/website-studio/:projectId
Step 6 — Preserve Existing Features

Do not remove:

existing generator UI
existing design input flow
prompts
business context collection

Only replace the generation engine underneath.

The user experience should remain:

Describe website
      |
Generate
      |
Studio opens
Step 7 — Remove Duplicate Generation Logic

After migration identify:

old JSON/template generation calls
duplicate preview generation
unused website generation services

Do not delete immediately.

Mark deprecated and keep fallback until V2 is verified.
