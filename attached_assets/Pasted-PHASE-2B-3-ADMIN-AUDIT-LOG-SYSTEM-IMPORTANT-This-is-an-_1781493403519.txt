PHASE 2B.3 — ADMIN AUDIT LOG SYSTEM

IMPORTANT:

This is an administration visibility layer.

DO NOT modify:

* authentication
* billing
* plan enforcement
* AI generation systems
* project architecture
* session monitoring

Build a dedicated Audit Log system.

==================================================
GOAL
====

Every important admin action must be permanently recorded.

Administrators must be able to answer:

* who did it
* what happened
* when it happened
* which user was affected
* from where

==================================================
DATABASE
========

Create table:

admin_audit_logs

Fields:

id
adminId
adminEmail
action
targetUserId
targetUserEmail
details (json)
ipHash
createdAt

Indexes:

adminId
targetUserId
action
createdAt

==================================================
TRACK EVENTS
============

Record audit entries for:

User Management

* promote user to admin
* remove admin role
* suspend account
* reactivate account
* change plan
* reset usage

Notifications

* send notification
* delete notification
* schedule notification

Future Billing

* manual subscription changes
* manual credits

==================================================
API
===

Create:

GET /api/admin/audit-logs

Filters:

date range
admin
action
target user

Pagination
