Prompt — Integration Audit & Wiring (No New Features)
Goal

Perform a comprehensive architecture audit of both Website Generator and Website Studio to identify every location where the new Marcus architecture exists but is not connected to the live execution flow.

This is an integration task, not a feature task.

Do not build new capabilities.

Do not create new prompts.

Do not add new abstractions.
