STAGEONE COPILOT v2 — PHASE 1

IMPORTANT:

Do NOT build autonomous execution yet.

Do NOT modify existing generation pipelines.

Do NOT modify routing.

Do NOT modify project persistence.

Do NOT modify Business Intelligence.

This phase is ONLY:

* workspace awareness
* project awareness
* memory awareness
* context awareness

====================================
GOAL
====

The current Copilot behaves like a disconnected chatbot.

It does not understand:

* current project
* current generation
* project history
* generated outputs
* workspace context

The Copilot must become workspace-aware.

====================================
REQUIRED CONTEXT
================

Whenever Copilot opens, automatically load:

Current Project:

* project id
* project name
* project type

Current Workspace:

* active page
* active module
* active generation

Generated Outputs:

* business intelligence
* website generations
* chatbot generations
* automation generations

Project History:

* previous generations
* timestamps
* linked outputs

====================================
COPILOT SYSTEM PROMPT
=====================

The Copilot must understand:

* everything currently visible
* project context
* generated intelligence
* website outputs
* automation outputs
* chatbot outputs

The user should never need to re-explain information already generated inside the project.

====================================
EXAMPLE
=======

User:

"What should I do next?"

Current project:

Healthcare Scheduling SaaS

Copilot should analyze:

* growth plan
* bottlenecks
* website status
* automation status

before responding.

====================================

====================

Current Project
Current Stage

Pending Modules

IMPORTANT

The Copilot should respond using project context automatically.
