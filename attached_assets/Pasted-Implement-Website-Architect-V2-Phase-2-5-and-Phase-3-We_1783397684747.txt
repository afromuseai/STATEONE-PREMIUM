PHASE 2.5 — Improve GeneratedProject Artifact

Current problem:

The Code Agent returns:

files: Record<string,string>

This works for initial generation but is not suitable for future editing, versioning, and AI modification.

Replace the file representation with an operation-based structure.

Update website-v2-types.ts.

Create:

ProjectFile

Example:

interface ProjectFile {
  path: string;
  operation: "create" | "update" | "delete";
  content: string;
  language?: string;
}

Update GeneratedProject:

interface GeneratedProject {

  projectId?: string;

  files: ProjectFile[];

  dependencies: string[];

  runInstructions?: {
    command: string;
  };

  preview: string;

  blueprint: WebsiteBlueprint;

  context: BusinessContext;

}

The goal:

Future agents should be able to modify individual files instead of regenerating the entire project.
