================================================

1. Create project retrieval routes

Create:

artifacts/api-server/src/routes/website-v2-projects.ts


Add:

GET /api/website-v2/projects

Purpose:
Return all Website Architect V2 projects belonging to the authenticated user.

Response:

{
 projects:[
   {
     id,
     projectName,
     status,
     createdAt,
     updatedAt
   }
 ]
}


Do not return full files in the list endpoint.

================================================

2. Add single project retrieval

GET /api/website-v2/projects/:id


Purpose:

Load a complete Website Architect V2 project.

Return:

{
 id,
 projectName,
 status,

 businessContext,

 blueprint,

 files,

 dependencies,

 preview,

 createdAt,
 updatedAt
}


This endpoint will power the future Website Studio workspace.

================================================

artifacts/api-server/src/lib/website-v2-projects.ts

Security requirements:
