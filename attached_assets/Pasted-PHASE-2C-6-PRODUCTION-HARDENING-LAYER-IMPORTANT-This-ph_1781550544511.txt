PHASE 2C.6 — PRODUCTION HARDENING LAYER

IMPORTANT:

This phase focuses on:

* security
* reliability
* abuse prevention
* recovery
* operational resilience

DO NOT:

* redesign UI
* change product logic
* change generation pipelines
* modify AI orchestration

This is infrastructure hardening only.

====================================

GOAL

Prepare STAGEONE for real users.

Build the systems necessary to safely operate a production SaaS.

====================================

1. RATE LIMITING

Implement centralized rate limiting.

Track:

* requests per minute
* requests per hour
* requests per day

Per:

* user
* IP
* endpoint

Limits:

Free:

* strict

Pro:

* moderate

Startup:

* high

Enterprise:

* configurable

Admin must see:

* rate-limit violations
* blocked users
* top requesters

====================================

2. ABUSE DETECTION

Create abuse monitoring.

Detect:

* excessive generations
* spam requests
* suspicious automation
* rapid account creation
* excessive login failures

Generate alerts.

Admin can:

* review
* dismiss
* suspend user

====================================

3. ACCOUNT SUSPENSION SYSTEM

Add:

users.isSuspended

Store:

* reason
* suspendedAt
* suspendedBy

Suspended users:

* cannot generate
* cannot access premium features
* can still access billing/support

Admin actions:

* suspend
* reactivate

Audit log every action.

* backup type

* database backup records

* latest backup
